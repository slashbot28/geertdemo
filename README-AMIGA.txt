================================================================================
GURU-EMULATION — COMMODORE AMIGA 1200 AGA DEMO
================================================================================
Geproduceerd voor: GURU-EMULATION / Geert Verhulst
Platform: Commodore Amiga 1200 (AGA Chipset, Motorola 68020+)

BESTANDEN IN DIT PAKKET:
1. guru-emulation.adf  - Standaard 880 KB Bootable Amiga Diskette (DF0:)
2. guru-emulation      - Standalone AmigaOS 68020 Hunk Executable (voor Hard Disk/CLI)

HOE TE GEBRUIKEN OP EEN AMIGA 1200 EMULATOR (WinUAE, FS-UAE, Amiberry):

OPTIE 1: RECHTSTREEKS BOOTEN VANAF DISKETTE (.ADF)
1. Start WinUAE, FS-UAE of Amiberry.
2. Kies het profiel: "Amiga 1200" (AGA Chipset, 2MB Chip RAM, Kickstart 3.0 of 3.1).
3. Laad "guru-emulation.adf" in Floppy Drive DF0:.
4. Start/Reset de emulator.
5. De diskette start automatisch op via s/startup-sequence en toont de demo!

OPTIE 2: UITVOEREN VANAF EEN HARDE SCHIJF / WORKBENCH
1. Kopieer het bestand "guru-emulation" naar een willekeurige lade (bijv. DH0:Demos).
2. Open een Amiga Shell / CLI venster.
3. Typ: guru-emulation
4. Druk op Enter.

BEDIENING IN DE DEMO:
- Linkermuisknop (LMB): Sluit de demo netjes af en keert terug naar Workbench / CLI.
- 50Hz/60Hz AGA Copper raster bars, 8-bit Paula chiptune arpeggio en Boing Ball animatie!
