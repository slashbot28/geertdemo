# Amiga 1200 AGA WebGL Demo - Geert Verhulst

An authentic Amiga 1200 AGA demoscene experience built in WebGL with Three.js.

## Features
- **Amiga 1200 Workbench 3.1** navigation bar and authentic color palette
- **Iconic 3D Boing Ball** with checkerboard texture and real-time shadow projection
- **Raster Copper Bar** gradient effects running at 60 FPS
- **Sine Wave 3D Text Scroller** with dynamic amplitude and retro typography
- **Interactive Stars & CRT Scanline Shader Overlay**
- **Procedural 8-bit / 16-bit Chiptune Sound Generator** with Web Audio API

## Live Demo
🌐 [https://geert-demo.web.app](https://geert-demo.web.app)

## Local Development
Simply open `index.html` in any modern web browser or serve it using any HTTP server:
```bash
npx serve .
```

## Deployment
Deployed to Firebase Hosting:
```bash
firebase deploy --only hosting
```
